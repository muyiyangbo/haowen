# AI辅助UI设计工具

## 项目概述

AI辅助UI设计工具是一个基于SOLO平台开发的智能设计助手，旨在帮助开发工程师快速生成UI设计方案并转换为代码，解决UI/UX设计资源不足的问题。

### 核心功能

- **AI设计生成**：根据用户需求描述，自动生成符合现代设计标准的UI界面
- **设计转代码**：将生成的设计自动转换为HTML/CSS代码，支持React、Vue等主流前端框架
- **组件库管理**：提供常用UI组件的存储、分类和检索功能，方便组件复用
- **快速原型构建**：支持通过拖拽组件快速搭建页面原型，实现可视化设计

## 技术栈

- **前端框架**：React
- **构建工具**：Vite
- **样式**：CSS3
- **AI能力**：基于SOLO平台的AI生成能力

## 使用指南

### 1. AI设计生成

1. 在「AI设计生成」标签页中，输入您的设计需求描述
2. 点击「生成设计」按钮
3. 等待AI生成设计方案
4. 查看生成的设计结果

### 2. 设计转代码

1. 在设计结果页面，选择目标前端框架（React、Vue或HTML/CSS）
2. 点击「转换为代码」按钮
3. 查看生成的代码
4. 点击「复制代码」按钮复制到剪贴板

### 3. 组件库管理

1. 在「组件库」标签页中，浏览可用组件
2. 使用搜索框或分类筛选组件
3. 点击组件卡片查看详情
4. 复制组件代码到剪贴板

### 4. 原型构建

1. 在「原型构建」标签页中，从左侧拖拽组件到画布
2. 调整组件顺序
3. 点击「预览原型」查看效果
4. 点击「清空画布」重新开始
